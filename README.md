## 📌 About The Project

Welcome to my **JavaScript Programming Lab Repository!**

This repository contains my practical assignments and laboratory work completed as part of the **JavaScript Programming Lab (BCS354)** during my B.Tech in Computer Science and Engineering.

The main objective of this project is to understand JavaScript fundamentals and develop programming skills through practical implementation.

It covers JavaScript basics, variables, data types, operators, conditions, loops, functions, arrays, JSON, objects, classes, inheritance, DOM manipulation, scope, closures, callbacks, higher-order functions, timers, promises, and asynchronous programming.

Each assignment is organized into separate folders, and individual programming tasks are maintained inside their respective Task folders.

## 🚀 How to Run

Follow these steps to access and run the project on your computer.

### Step 1: Install Node.js

Check whether Node.js is installed:

```bash
node -v
```

Check npm version:

```bash
npm -v
```

### Step 2: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Step 3: Open the Project Folder

```bash
cd js_lab
```

### Step 4: Open in Visual Studio Code

```bash
code .
```

### Step 5: Open a JavaScript Assignment

For example:

```text
Assignment1/
    └── Task1/
        └── task1.js
```

### Step 6: Run the JavaScript File

```bash
node task1.js
```

### Step 7: View the Output

The output will appear in the VS Code terminal.

**For HTML-based JavaScript programs:**

1. Open the required HTML file.
2. Run it in Google Chrome.
3. Press F12 to open Developer Tools.
4. Select the Console tab.
5. Check the JavaScript output.
